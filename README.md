# PersianChat 1.1

پلاگین Paper برای نوشتن فارسی در چت، تابلو و کتاب، برای بازیکن‌های جاوا و بدراک
(حروف متصل و ترتیب درست). نیازی به دیتاپک یا ریسورس‌پک ندارد.

## ساخت jar (با GitHub Actions)
1. یک ریپوی جدید در GitHub بسازید و همهٔ فایل‌های این پوشه را آپلود کنید (پوشهٔ `.github` هم باید باشد).
2. تب Actions ← workflow به نام build ← بعد از تمام شدن، `PersianChat` را از Artifacts دانلود کنید.
3. `PersianChat.jar` را در پوشهٔ `plugins` سرور بگذارید و ریستارت کنید.

## چطور کار می‌کند
- **چت:** برای هر بیننده جدا شکل‌دهی می‌شود. جاوای با زبان فارسی/عربی متن اصلی را می‌گیرد (`raw-languages`).
- **تابلو:** هر خط هنگام ذخیره شکل‌دهی می‌شود.
- **کتاب:** هر خط فارسی هنگام ذخیرهٔ کتاب (Done یا Sign) به خطوط کوتاه شکسته و جداگانه شکل‌دهی می‌شود.
  طول خط با `book-line-chars` در config.yml تنظیم می‌شود (پیش‌فرض ۱۴).

## نکته‌های استفاده
- تابلو و کتاب برای بازیکن‌هایی درست دیده می‌شوند که زبان بازی‌شان **انگلیسی** است.
- متنی که یک بار شکل‌دهی شده دوباره دست نمی‌خورد. برای ویرایش یک خط فارسی در تابلو یا کتاب،
  آن خط را پاک کنید و دوباره بنویسید (اضافه کردن به وسط خط شکل‌داده‌شده کار نمی‌کند).
- اگر خطوط کتاب جدا از هم شکسته یا به‌هم‌ریخته دیده شد، `book-line-chars` را کمتر کنید.
- مقدار مناسب این عدد برای جاوا و بدراک ممکن است کمی فرق کند؛ با یک نمونه تست کنید.
